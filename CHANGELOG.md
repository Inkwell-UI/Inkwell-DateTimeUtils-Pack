# Changelog

## 0.1.0

First release: 7 pure nodes (category Time), all `datetimeutils/<Kind>@1`.

- Durations (seconds): Format Duration, Get Duration Part, To Seconds, Format Time Ago.
- Clock and calendar text: Format Time Of Day, Month Name, Weekday Name.

Nothing here uses the Flash `Date` class. Negative or non-numeric durations count as 0.
